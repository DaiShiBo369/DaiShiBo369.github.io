背景：先从能写小 GUI 开始

这篇文章采用 Qt Widgets + C++ 作为入口。原因很简单：Qt Widgets 更适合快速理解传统桌面程序结构，也能直接暴露 Qt 的几个核心概念：事件循环、信号槽、QObject 对象模型和布局管理器。

QObject 父子对象：为什么 new 了不用 delete

如果只从普通 C++ 的 new/delete 角度看，会自然追问：为什么没有 delete button？

Qt 的答案是 QObject 父子对象机制。很多 Qt 类都继承自 QObject，可以形成父子对象树。当父对象销毁时，Qt 会自动销毁它的子对象。

例如：

MainWindow 销毁时，button 和 layout 会被一起释放。所以对于已经指定父对象的 Qt 对象，通常不要再手动 delete，否则可能破坏对象树管理，甚至带来重复释放风险。

需要注意的是，Qt 的父子机制只适用于 QObject 体系。普通 C++ 类不会因为写了类似关系就被 Qt 自动管理。

阶段性结论

Qt Widgets 入门可以先抓住五句话：

  1. Qt GUI 程序需要 QApplication 和事件循环。
  2. QWidget 是最基础的窗口/控件类，创建后要 show() 才显示。
  3. 信号表示对象发生事件，槽表示事件发生后要执行的代码。
  4. QObject 父子对象机制负责管理很多 Qt 对象的生命周期。
  5. 真实界面优先使用布局管理器，不要依赖手动坐标。

理解这五件事后，再继续学习菜单、对话框、文件读写、资源文件和多窗口结构，会顺很多。
